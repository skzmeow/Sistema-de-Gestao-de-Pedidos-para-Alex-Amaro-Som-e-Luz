<h1 align="center">Sistema de Gestão de Pedidos para Alex Amaro Som & Luz</h1>

O objetivo do projeto é aplicar, em contexto real, técnicas de levantamento e especificação de requisitos, mpdelagem de sistemas e prototipagem de soluções computacionais em parceria com a empresa Alex Amaro Som & Luz que atua no setor de som e iluminação para eventos há 40 anos no mercado.
