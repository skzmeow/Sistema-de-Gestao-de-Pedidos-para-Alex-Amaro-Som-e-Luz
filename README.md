<h1 align="center">Sistema de Gestão de Pedidos para Alex Amaro Som & Luz</h1>

O objetivo do projeto é aplicar, em contexto real, técnicas de levantamento e especificação de requisitos, modelagem de sistemas e prototipagem de soluções computacionais em parceria com a empresa Alex Amaro Som & Luz que atua no setor de som e iluminação para eventos há 40 anos no mercado.

## Tecnologias e Ferramentas

[Figma](https://www.figma.com/)  
[Draw.IO](https://app.diagrams.net/)  
[Lucidchart](https://www.lucidchart.com/)  
[XAMPP](https://www.apachefriends.org/pt_br/index.html)  
[BrModelo](https://www.zigg.com.br/downloads/brmodelo/)  


## Organização do Projeto

`docs/front-end/`: Protótipos e wireframes de alta fidelidade + desenvovlvimento em HTML, estilização em CSS e funcionalidades em JavaScript

`docs/relatorios/`: Contextualização + requisitos, modelagem, prototipagem e testes + planoo de segurança inicial
